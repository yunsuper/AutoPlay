# AutoPlay  
### (video-autoplay-bookmarklet)

Generic HTML5 Video AutoPlay Bookmarklet for personal automation.

This project is intended for **personal automation and educational purposes only**.  
The author is **not responsible for any misuse** of this tool.

본 프로젝트는 **개인 자동화 및 학습 목적**의 도구입니다.  
본 도구 사용으로 발생하는 **모든 책임은 사용자 본인에게 있습니다.**

---

## ✨ Features
- Automatically plays HTML5 videos
- Automatically clicks "Next Video" buttons when available
- Keyboard shortcut to toggle ON/OFF
- IME-safe (Korean/Japanese/Chinese input safe)
- Input/textarea focus-safe
---
- HTML5 비디오 자동 재생
- "다음 영상" 버튼 자동 클릭 (존재할 경우)
- 단축키(Enter)로 ON / OFF 전환
- IME 입력 안전 (한글 / 일본어 / 중국어 입력 중 오작동 없음)
- 입력창(input, textarea) 포커스 시 자동 동작 차단

---

## ⚠️ Disclaimer
This tool does **not bypass DRM, authentication, payments, or access restrictions**.  
It only automates **user-visible HTML interactions**.

---

## ✅ Usage
1. Register the script as a browser bookmark.
2. Open a page containing an HTML5 video.
3. Click the bookmark.
4. Toggle AutoPlay using the **Enter key**.
---
1. autoplay.js 코드를 **브라우저 북마크(북마클릿)**로 등록합니다.
2. HTML5 비디오가 포함된 웹페이지를 엽니다.
3. 등록한 북마크를 클릭합니다.
4. Enter 키를 눌러 AutoPlay를 ON / OFF 전환할 수 있습니다.
